## 🛠️ Currently building

> ### [OPEN](https://opendev-tx-solana.vercel.app) — _Chrome DevTools for Solana._
>
> One transaction signature in → a fully decoded execution profile out. Compute units, CPI call tree, account diffs, and AI-augmented insights.
>
> [`🌐 Web`](https://opendev-tx-solana.vercel.app) · [`📚 Docs`](https://open-dbe26606.mintlify.app) · [`🐦 X`](https://x.com/OpenDevT) · [`💻 Repo`](https://github.com/OpenSubmissionn/Open_DevTool)

```sh
npm install -g opendevtool
opendev tx <SIGNATURE> --network mainnet
```
